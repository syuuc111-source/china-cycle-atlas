# 中药与相术专题

用户请求以六份本地PDF开辟两个新专题。继承既有深色阅读界面与导航，不公开PDF全文或原始OCR。

## 内容与范围

- 中药：黄煌《张仲景五十味药证》50味药全部建条，6篇概念导读；倪海厦讲义用于药性总论与46个相关条目的目录对照，不宣称全书逐条编校。
- 相术：26个名词条目、面部位置导览、3个文本来源说明；解释历史术语与版本差异，不依据外貌推断人格、道德、性行为、财富、疾病或寿命。
- 五个文本来源对应六个文件；两份《面相手相宝典》按相同文本的标注副本处理。
- 所有书目使用PDF物理页码。作者和版次未确认处标明待考。现代使用提醒与原书观点分栏，药方不提供剂量或自动推荐。

## 核对记录

扫描版使用Windows OCR辅助检索，按选题读取章节并核对重要页面。药证目录第49味为䗪虫（土鳖虫），非虻虫；作者为黄煌，非张仲景。《太清神鉴》文件自身包含冲突作者题署，不沿用“禁书”营销名称。

两份《宝典》低分辨率逐页渲染比较，383页中382页像素一致；PDF第72页一份多红色划线。原始文件及核对图片留在网站仓库之外。正文全为原创摘要；不把水印、制作署名认定为作者。

外部现代资料：沿用香港卫生机构药剂/附子资料，补读NCCIH甘草和麻黄安全页面。原书章节定位不代表支持现代医学结论。
