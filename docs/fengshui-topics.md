# 两个独立风水专题

入口为 `ganzhi/#fengshui`（阳宅）与 `ganzhi/#yinfengshui`（阴宅）。共同导航提供两个独立图标，首页、检索状态、阅读目录、书目分别管理。

阳宅：18 篇概念与空间解释、23 项选择准则辨读、5 种资料。准则源文主要处于相地与墓葬语境，不当作城市购房标准。首页提供北向上的二十四山等分方位识读，不读取设备或判断吉凶。

阴宅：20 篇术语与辨读、8 种格局摘要、72 项原书标题和页码索引、9 种资料。两份内部教程文件完全相同，合并为一项。72 项索引来自正针与兼向标题，不等同穿山七十二龙，未宣称完整校勘所有正文。首页图形为相对关系示意，不设绝对方位。

数据由 `scripts/ganzhi_fengshui.py` 与 `scripts/fengshui_index.py` 生成。只发布原创解释、短标题索引与书目，不发布 PDF 或提取全文。每种书分别说明实际核读范围；扫描、乱码和未编校部分明确列出。页码从 PDF 第一页起计。

验证：`node tests/fengshui-browser.cjs` 检查 141 个条目、14 种书目、引文范围、搜索状态隔离、罗盘键盘选择、手机和平板布局与导航。共享导航还运行 books、body、acupuncture 浏览器回归测试。独立来源审查校正了中阴格局的左水倒右方向。
