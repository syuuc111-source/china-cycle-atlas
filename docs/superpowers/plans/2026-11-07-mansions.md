# 二十八星宿 Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 发布与原图谱互链的二十八宿专题网站，提供星图导览、28 宿百科、传统体系与出处。

**Architecture:** 在现有 Pages 仓库的 `mansions/` 下部署独立视觉与导航的静态网站。内容数据、可核实的星图数据、展示与状态逻辑分离；URL hash 保存栏目和星宿，静态资源随站点发布。

**Tech Stack:** HTML、CSS、原生 JavaScript modules、SVG/Canvas、Node assert、Playwright / Edge、GitHub Pages。

**Spec:** `F:/周期率/二十八星宿网站设计草案.md`（用户已确认）。

## Global Constraints

- 四象各七宿，共28宿；每宿概览、天文说明、文化说明与来源。
- 文字与交互动画，无配音；不做日期地点驱动的观星模拟。
- 深色星空、米白宋体、青绿/朱红强调；五行沿用木绿、火红、土橙、金金、水蓝。
- 等宽导航标为示意，天球非当地实时天空；传统体系各自说明来源。
- 桌面、手机、键盘、减少动态模式和加载失败均可用。
- 独立专题网址与原图谱互链；实际在线验收后交付。

## Review Focus

- 未知hash、浏览器后退与深链接：恢复一致的章节/宿/四象状态。
- 搜索空值、异体字、无结果：清楚反馈且可清除。
- 手机窄屏与键盘：星图之外也有全部可操作宿按钮，弹窗可关闭且恢复焦点。
- 用户暂停、切换标签、减少动态偏好：动画不会自行恢复或占用后台。
- 资料请求失败：显示可重试信息，不留下空白页面。
