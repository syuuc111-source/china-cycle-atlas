# 天干地支专题网站 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for the recommended native execution method, or superpowers:subagent-driven-development if the user selects that method. Steps use checkbox syntax for tracking.

**Goal:** 建成并发布兼顾入门学习、百科查阅和可靠日期查询的天干地支专题，与中国周期图谱、二十八宿互通。

**Architecture:** 采用现有仓库的静态 HTML、CSS 和浏览器 ES module 模式。知识条目、纯干支规则、历算适配器、循环盘与页面渲染分别管理；使用 hash 路由，支持 GitHub Pages 深链接。日期在浏览器本地计算，运行时不请求第三方历算服务。

**Tech Stack:** 原生 HTML/CSS/JavaScript、Node.js node:test、既有 Playwright＋Edge；候选历算依赖 lunar-javascript 1.7.8（MIT）本地固定版本，经独立核验后采用。Python 只用于主站既有构建和本地 HTTP 服务。

**Spec:** `docs/superpowers/specs/2026-11-10-ganzhi-design.md`，用户于2026-11-10批准。

## Global Constraints

- 五行语义色：木 #348b50、火 #d7443e、土 #e88328、金 #c9a32c、水 #307dc0。
- 日期范围为公历1901—2100年；输入解释为固定 UTC+08:00 标准时间，不自动套历史夏令时。
- 农历纪年正月初一换年；节气四柱使用立春年界和十二节月界，两种结果分区展示。
- 日界默认00:00，可比较23:00口径；时干随选定日干计算。界面不得暗示已支持真太阳时。
- 内容覆盖规格的11个分区，22个干支基础条目及60个甲子条目；以实际说明和出处完成，不以空标题或模板命运断语充数。
- 传统理论、历史材料、历法／数学、流派异说分开标记；待核验检索摘要不能作为已读原典。
- 深链接、手机适配、键盘操作、暂停和减少动画必须可用。
- 保留原站数据、五行颜色含义与分析行为；主站构建继续从 src/atlas/ 生成 index.html。

## 数据与接口契约

```js
// content.json
// {version, guides: Guide[], entries: Entry[], articles: Article[]}
// Entry: {id, kind:'stem'|'branch', name, pinyin, aliases:string[],
//         summary, sections:Section[], related:string[], sourceIds:string[]}
// Article: {id, title, category, aliases:string[], summary, sections:Section[],
//           related:string[], sourceIds:string[]}
// Section: {heading, paragraphs:string[], evidenceType, sourceIds:string[]}
// Source: {id, title, author, url, locator, checkedAt, status, supports:string[]}
// Guide: {id, title, paragraphs:string[], articleIds:string[], cycleIndex:number}

// model.mjs
// cycleAt(index:number) -> Cycle
// Cycle: {index, name, stem, branch, stemElement, branchElement,
//         polarity, nayin, nayinElement, xunHead, voidBranches:string[]}
// hourPillar(dayStemIndex:number,hour:number) -> string

// calendar.mjs (pure numeric input, never parse a locale-dependent Date string)
// queryCalendar({year,month,day,hour,minute,dayBoundary:'midnight'|'zi'})
// -> {ok:true, civil:{date,lunarDate,yearPillar},
//     solar:{year,month,day,hour}, rules:{timezone,year,month,day,hour},
//     precisionNote, sourceIds:string[]} | {ok:false,code,message}

// wheel.mjs
// mountWheel(container:HTMLElement,{index:number,onSelect:(index)=>void})
// -> {select(index):void,setPlaying(value:boolean):void,destroy():void}
// app.mjs owns selection; wheel notifies user actions, select() never re-emits.
```
