# 二十八星宿 · 网站设计草案

状态：用户已确认视觉与整体设计，2026-11-07实现。

## 已确认的需求

- 独立星宿专题网站，与“中国周期图谱”互相链接。
- 导览与百科结合，覆盖全部二十八宿。
- 天文学、历史文献、神话、宗教与术数广泛收录，按体系标明来源，不混用计算。
- 文字与交互动画，无配音。
- 四象与二十八宿导航、点击星图查看讲解、章节动画；不做日期和地点驱动的实时观星模拟器。

视频只作为视觉和叙事参考；画面中的科学结论、诗文解读与星宿位置仍需另行核实。

## 推荐设计

### 页面结构

1. **入门导览**：什么是宿 → 二十八宿的历史证据 → 四象 → 月亮与历法 → 诗文与文化。每章一个主要交互，支持上一章、下一章和直接跳转。
2. **四象星图**：选择苍龙、玄武、白虎、朱雀，突出对应七宿；点击某宿打开详情。桌面左文右图，手机星图与正文上下排列。
3. **二十八宿百科**：按四象筛选、按名称及别名搜索，每宿有可分享链接；包括一分钟概览、名称含义、主要星官与现代对应、文献与文化、来源。
4. **传统体系专题**：分别介绍七曜禽星、五行、神话神祇、分野、值宿与宿曜。明确不同传统的时代、用途与差异，文献所载吉凶作为传统观念介绍。
5. **文献与出处**：正文关联来源条目，标注文献章节或机构页面；现代对应存在争议时保留说明。

### 视觉与交互

- 深色星空、米白宋体大标题、清晰易读的中文正文，细线边框和星图。
- 四象采用青绿、蓝、浅金、朱红；五行标识沿用原站的木绿、火红、土橙、金金、水蓝，图例明确区分两种含义。
- 首页从星空总览进入四象，选择某宿后突出相应星点和连线，正文同步更新。
- 天球旋转和镜头聚焦用于讲解，提供暂停与减少动态效果支持。
- 天球装饰与真实位置图分开标识；未核实坐标不能冒充真实观测星图。等分的二十八宿导航环标为示意，不代表各宿实际宽度。
- 出处随正文可展开，保持阅读主界面简洁。

## 内容与验收

- 28 宿逐项建档，四象各 7 宿，名称、顺序、归属可追溯核对。
- 每宿至少提供概览、天文说明、文化说明与来源；没有可靠材料的字段明确说明，避免填造。
- 不承诺穷尽全网所有知识；构建可持续扩充的资料库，说明覆盖范围。
- 历史最早证据与起源推测分开；二十八宿、星官、现代星座分开；月亮恒星月与朔望月分开。
- 搜索、四象切换、星宿点击、详情深链接、章节跳转、返回与原站互链均需浏览器验证。
- 检查手机布局、键盘操作、文字对比度、减弱动态模式和加载失败提示。
- 发布后核验实际网址可访问及关键交互，再交付新站链接。

## 实现方向

采用静态站点与结构化内容数据，复用现有 GitHub Pages 发布方式。星图展示与正文数据分离，确保补充来源和修订星宿条目时不影响导航。优先使用 SVG / Canvas 实现星图与动画，根据经核实的数据决定哪些视图使用真实星位。实现前形成可执行计划。
