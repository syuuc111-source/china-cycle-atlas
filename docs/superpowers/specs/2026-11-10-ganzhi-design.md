## 目标与既有决定

为中文读者制作可以从零学习、深入查阅并实际查询日期干支的网站。用户要求广泛收录与天干地支有关的知识。通过可扩展的内容目录、逐条出处和明确的流派标记实现广泛覆盖，不宣称穷尽所有古籍、地域习俗与学派观点。

沿用已有项目的五行语义色：木 #348b50、火 #d7443e、土 #e88328、金 #c9a32c、水 #307dc0。文字和互动动画为主。现有主站与二十八宿专题继续使用。

## 方案比较与推荐

1. 导览＋百科＋日期工具（用户已选）：入门与长期查阅兼顾，需要明确计算口径并验证边界。
2. 导览＋百科：讲解容易集中，但不能满足这次已选的日期查询需求。
3. 古籍研究入口：适合熟悉术语的读者，学习门槛较高；作为推荐方案里的进阶分区。

建议在现有仓库新增 ganzhi/ 独立专题，与主站、mansions/ 互相链接。拟定名称「干支 · 时间之序」。部署后的目标地址为现有 GitHub Pages 域名下的 /china-cycle-atlas/ganzhi/；地址须在发布验证成功后才对外宣布可用。

## 页面结构与读者路径

- 首页／从零开始：以「十个天干、十二个地支，为什么只有六十个组合」进入可操作循环盘；分步解释配对、阴阳奇偶和周期。
- 十干十二支：22 个独立可链接条目；每条包括读音、顺序、基本对应、相关概念、历史解释与出处。加入戊／戌／戍、己／已／巳辨认；古代字形训释与现代记忆法分列。
- 六十甲子：完整60组合，按序号、天干、地支、五行或纳音筛选；点击条目联动循环盘与解释。分别标明干五行、支本气及纳音。
- 知识图解：阴阳、五行生克、四季方位、时辰、节气、合冲等；图解始终有文字或表格替代。
- 历法与日期查询：公历日期时间输入，明确的规则选择，年／月／日／时干支结果，逐项解释计算所用口径。
- 深入阅读：传统术数、医籍运气、历史民俗及东亚传播，按主题交叉链接。
- 文献与方法：参考文献、证据性质、术语索引、争议与修订记录。全站搜索标题、别名及正文摘要。

## 日期查询口径

- 建议首版支持公历1901—2100年，以固定 UTC+08:00 标准时间解释输入，不自动套历史夏令时。内部数据覆盖范围两端计算所需的相邻年份。范围与时区始终可见；无效日期和越界输入给出明确错误。
- 农历纪年采用正月初一换年；另列立春交节换年的传统术数口径。默认先展示农历纪年，同时允许比较，不把两者混成单一结果。
- 节月按十二个「节」的交节时刻划分，月干按对应年干规则推导。农历月名称另列，不以农历初一替代节月边界。
- 界面分为「农历日期与纪年」及「节气干支年月日时」两个清楚命名的结果区；后者年柱与月柱统一采用立春／节月口径。春节纪年可并列比较，不能任意替换节月体系的年干。中气不会触发月柱切换。
- 立春、交节计算必须使用经过核验的历算库或已核验数据；记录来源、许可、时间尺度和误差。接近精度边界时显示限制，不假称秒级准确。
- 日干支依连续日数与已核实锚点计算。默认00:00换日；可比较23:00换日的明确约定。采用哪一日推时干须与所选规则一致。其他子时流派在说明中介绍。
- 时支按十二时辰划分，时干按所选日干规则推导。结果展示采用的年月界、日界、时区，并可展开推导步骤。
- 不在首版自动将用户输入转换为出生地真太阳时；讲清标准时间、地方平太阳时、真太阳时的区别。无需收集姓名或地点。
- 历史文章可以讨论古代，1901年以前的实际日期转换不在这个首版工具的验证范围；不能将现代历法无限回推后宣称真实历史历日。
- 现有图谱1984年锚定的年度标签仅可复用为循环说明，不直接用作日期转换。

## 视觉与交互

深靛蓝背景、宋体主标题、清晰正文，青金色界面强调。首页使用原创同心循环盘，内层10干、外层12支，配合60步进度；下一步／上一步／播放／暂停都可操作。选择第61步回到甲子，直观显示完整循环。

五行颜色用于对应意义；标签同时包含汉字和阴阳说明，不能只靠颜色辨识。深色背景上的正文使用足够对比的前景色，既有五行颜色可作色块、边线或图形。

切换时旋转与内容过渡联动，连续点击能取消旧动画并保持选择一致。关闭动态效果或系统减少动画时，功能完整，装饰动效停止。百科采用宽松排版、侧边目录／移动端折叠目录；长表格提供适合手机的条目视图。

## 数据与技术边界

沿用静态 GitHub Pages；内容数据、干支规则、日期转换和UI分层。来源条目至少包含标题、机构或作者、URL、获取状态、支持的论点及核验日期；文章引用来源ID。每条内容标注「历法／数学」「历史材料」「传统理论」「存在分歧」等适用标签。

所有条目和页面有稳定链接，支持刷新与浏览器前进后退。搜索与日期输入在浏览器内处理。依赖在采用前检查许可证、维护状况和计算边界；不在设计阶段指定未经调查的历算包。

## 验收标准

- AC-01：22基础条目和60组合齐全、唯一、顺序正确；60步循环回到起点，非法阴阳组合不进入60甲子表。
- AC-02：覆盖清单每行都有实质文章；正文关键断言可追溯到具体来源，未读全文的检索线索不标为核验完成。
- AC-03：可按名字、别名和相关术语找到条目，提供无结果状态；相关链接与文献跳转正确。
- AC-04：完整日期范围验证，拒绝非法输入；与独立可信参考核对范围首尾、普通日期、闰日、春节、立春、十二节交界、闰月年份（包括2033年问题）、22:59／23:00／23:59／00:00／00:01；不得仅与同一实现的输出互证。
- AC-05：不同年界或日界下发生差异时，界面可比较结果并解释差异。节月与农历月不混称。
- AC-06：循环盘鼠标、触摸、键盘均可操作；连续切换不出现选项与详情不同步；播放可暂停，减少动画模式有效。
- AC-07：至少在390、768、1440像素宽度验证关键页面与长中文内容；无整页横向溢出，焦点清晰，正文对比度达到WCAG AA。
- AC-08：主站、二十八宿、干支专题入口互通；新专题修改不破坏现有主站和星宿功能。记录本地与发布后的实际验证结果。
